# Model layer: Seedream 5.0 Pro (the team's default for character and location sheets)

> The masters in `masters/` were written for this model. When the user picks a **Seedream** prompt, use them exactly as they are.

- **Use Seedream 5.0 Pro, never the standard Seedream 5.0**, whenever the Pro version is available. Any app that offers Seedream 5.0 Pro is fine.
- **Base sheet:** the complete selected master, byte for byte, then two line breaks, then the character description. Long "NO …" constraint lists are part of the master; keep them.
- **Aspect ratio 16:9** for character reference sheets (5 full-body views on one wide canvas). Locations: one wide image.
- **Transition edits:** add the ORIGINAL Before/base sheet as the reference image in the app, then paste only the edit prompt (no master). Never chain from the previous stage's image.
- **3-view instead of 5:** when the character will only ever be shown from the chest up, a 3-view sheet (front, 3/4, profile) is enough. Keep the master and add one line to the character description: "Show three chest-up views instead of five full-body views: front, 3/4 front, left profile."
- **Review every output** with the Final Editor Check (`references/theory.md`) and the transformation checks (`references/workflow.md`). The output is a starting point, not the final reference.
- One model per character: every sheet and edit of a character stays on Seedream once it starts there.
