# Workflow: script → cast plan → base sheets → transitions

## Intake

For a new script-wide run, ask for the **full script first**, unless already supplied. Read it to identify essential characters, the actual concern, and any visible transitions. Next ask for the render style using the numbered list below, unless already supplied. Before presenting the cast plan, ask for the **target audience only if it is unclear in the script and has not been supplied**: “Who is this ad for? Age, gender, and US background if known.” Use the answer to refine casting. If the script clearly establishes an audience, use it and briefly state the interpretation with the plan. Do not make audience intake a mandatory first question.

The sequence is **script → style → audience clarification if needed → cast, transition, and location plan → user approval → prompts**. Keep the workflow active across subsequent messages even if the skill is not named again. For a quick standalone example with a specified character, skip script-wide cast approval; use the supplied style or ask for it when needed to choose its master.
For random examples when no audience is specified, choose among **White, Black, or Latino** characters, varying age, gender, build, and styling. These are the user's current ad audiences. If the user explicitly requests another background, follow that request. Do not infer that every script character must share the target audience's background; follow the script's cast.

## Find the cast

1. Read the whole script. Identify recurring people across scenes, including a named character referred to later by a role or pronoun. Keep the same person under one entry; preserve their name when the script gives one.
2. Keep the cast as small as possible. Include the main character; a recurring doctor, friend, partner, or product introducer when visually important; and a one-scene character only when that person is essential to understanding the story or explicitly requested. Skip background crowds, incidental extras, offscreen mentions, generic patients, and people who do not need consistent identity. The same person at multiple times is **one character with multiple reference states**, not multiple cast members.
3. Do not invent a personal name. Label unnamed characters by a stable role, such as “Woman at the barbecue” or “Husband.” If two characters share a role, distinguish them plainly.
4. Use the target audience and script to choose plausible age, dress, and visible traits; keep distinct people visibly different. For creative casting in this user's ads, ground each person in a short, plausible **US everyday context**: where they live or spend time, what ordinary occasion this outfit belongs to, and an individual habit or preference if useful. Use a scripted background first. Otherwise choose a fictional context consistent with the script and mark it as a casting choice, not a fact inferred from a face. Family origins such as Irish-American or British-American may be used when supplied or when they genuinely help a particular fictional character, but do not assign ancestry, personality, occupation, religion, or class based on skin tone, clothing, or one line of dialogue. When a needed visual choice remains open, choose it deliberately and keep it consistent. Keep any reference image's defining features.
5. Use `references/vocabulary.md` for facial vocabulary and hairstyles. Its Black hairstyle chart applies to Black characters only. Use `references/wardrobe.md` to vary clothing and grooming based on the user's real-person outfit examples.

## Propose the reference-sheet plan before writing prompts

Read the whole script and identify its **actual concern and promised or depicted transformation before deciding how anyone looks**. Separate visible physical change from internal, functional, sensory, emotional, or relationship change. Then list only the required **people** and the required **visual states** for each. Plan essential location references separately using the location workflow below. Put the main character first. For each state give the script's scene or time marker, the outward change that needs to be shown, and whether it needs a separate image. Internal-body mechanism shots are not human character sheets; use the mechanism only to understand any explicitly depicted outward progression. Do not invent a visible health result from internal narration alone.

Match the reference plan to the script's concern:

- **Weight loss, bloating, or visible swelling:** make the specified exterior change legible and progressive. A weight-loss story can have a heavier before and a slimmer later silhouette, less facial puffiness, or changed clothing fit when the script supports those beats.
- **Erectile dysfunction or another functional concern without a visible body transformation:** keep the person's face, weight, build, and skin consistent. Do not add belly fat, a double chin, swelling, or weight loss as a proxy for the issue. If the script shows a clear before/after presentation, make the later version look more awake and at ease through expression, posture, grooming, or a better-chosen outfit; keep their identity and natural features recognizable.
- **Vaginal odor or another sensory intimate concern:** odor has no inherent visible body shape. Use the character's established appearance; do not invent weight loss, swelling, genital appearance, discharge, stains, or other visible symptoms. Keep the reference sheet clothed and non-explicit. A visible change in expression, posture, grooming, or outfit can show increased comfort or confidence when the script depicts it.
- **Other concerns:** identify the script's exact visible markers, if any. When the change is primarily emotional, functional, or social, use a distinct after sheet only if the script depicts a meaningful change in presentation; otherwise reuse the base sheet.

For a nonphysical before/after, show the contrast through a few specific, visible choices: tired-looking or less engaged eyes becoming alert, a guarded or slouched stance becoming upright, a serious expression becoming an open smile, or a more considered outfit that still suits the same person and occasion. Do not stack every cue by default, imply a physical symptom the script does not show, or turn the after into a different person or change their chronological age. A fresher, slightly younger-looking presentation is allowed while they still look their age. Keep performance and scene actions out of the appearance prompt.

Give the main character one complete **Before / base** reference. Add a new state for each depicted, visually distinct milestone: 24 hours, one week, later weeks, final after, etc. If the script actually shows a week-by-week six-week progression, plan six weekly variations and count the base separately; if it only shows before and week six, plan those two. Do not manufacture six sheets merely because the ad mentions “six weeks.” Mark unchanged time points as reusing the preceding sheet. State the total number of characters and reference images transparently.

Present this as a compact proposal, e.g. `Main woman — Before base, 24 hours (face less puffy), week 1 (waist fit), week 6 (final); Doctor — one stable sheet; Total: 2 people, 5 images.` Include a one-line audience assumption for confirmation when inferred. Then **pause for the user's “okay” or correction**. Do not generate full prompts before that approval. Render style has already been selected.

## Select render style after the script

Ask for one style in a plain numbered text list, accepting either its number or name:

1. Pixar — simple cartoon / less HD.
2. Pixar high fidelity — crisper render with realistic surface detail.
3. Realistic Movie.
4. UGC iPhone.

Do not add clickable controls, a plugin UI, or an external website for this choice. Read the selected master in full before assembling a base prompt:

| Style | Unchanged master | Location master |
| --- | --- | --- |
| Pixar — simple cartoon / less HD | `masters/characters/pixar-simple.md` | `masters/locations/pixar.md` |
| Pixar high fidelity | `masters/characters/pixar-high-fidelity.md` | `masters/locations/high-fidelity.md` |
| Realistic Movie | `masters/characters/realistic-movie.md` | `masters/locations/realistic-movie.md` |
| UGC iPhone | `masters/characters/ugc-iphone.md` | `masters/locations/ugc.md` |

**Generation model: ask the user, after the style, whether they want a Seedream 5.0 Pro prompt or a Nano Banana Pro prompt** (see SKILL.md and `references/models/`). Seedream 5.0 Pro is the team's default for these masters; when Seedream is chosen, use Seedream 5.0 **Pro**, never the standard 5.0. Keep the chosen model for every later sheet and edit of that character; never switch models mid-character. Do not generate images unless requested.

Above **every** base or edit prompt, prominently show **Generation model: [model label]** outside the copyable block. For later states also say **Upload the already-created Before reference image of the main character.** Identify which character's base sheet to upload if there are several characters.

### Base prompts: exact master plus appearance

For the first reference sheet of every character, including supporting characters, copy the selected master **byte for byte** into a fenced `text` block, then append two line breaks and the appearance description. Preserve the entire master including its final heading and placeholder. Do not replace the placeholder, trim, shorten, paraphrase, correct, reorder, remove studio names, or change any master wording or formatting. The appended description supplies the person requested by that placeholder.

All four masters now specify five full-body views. Do not append an older four-view layout or face close-up instruction. The selected master governs render technique, camera, lighting, pose, materials, proportions, and layout. Adapt the character description to it; never alter the master to resolve a conflict with older general guidance. Both animated styles require strongly exaggerated faces and bodies: visibly enlarged heads, large expressive eyes, bold facial forms, and exaggerated torso-to-limb proportions. Their difference is surface treatment: simple cartoon uses cleaner simplified surfaces, while high fidelity adds richer skin texture, hair strands, and fabric detail to equally cartoonish geometry. Do not append slouched or action poses that conflict with the masters' neutral standing poses. A before expression can remain serious within a neutral reference pose.

Keep camera, lighting, motion, dialogue, location, and product directions out of the appended character description. The master already provides the technical sheet instructions.

### Later transitions: edit only

For all later states of the same character, **omit the style master**. Above each complete copyable edit prompt, show the bold generation-model label and say **Upload the already-created Before reference image of [character].** Use the original Before/base sheet for every milestone, not the preceding edited image.

Keep edit instructions simple and direct. Use the Before image to retain recognizable identity, with a short reminder such as “same woman, recognizable identity, eye color, skin tone, and natural hair color.” Keep their chronological age. Let the reference carry the existing render style and sheet layout rather than adding a long preservation checklist. Do not preserve the exact body shape, double chin, puffiness, eye bags, or outfit when those are meant to change. Identity preservation must not cancel the transformation.

**Do not write “keep everything the same,” “keep all other details unchanged,” or “only change” followed by a restrictive preservation checklist.** These blanket locks can suppress the transformation. Reference the Before image, briefly identify the same person, then directly request the changes and the new outfit. For example: “Use the attached Before sheet as the reference for the same woman. Make her stomach noticeably smaller and her waist slimmer. Remove the under-eye bags and reduce the double chin. Give her a brighter, more alert face while she still looks her age. Dress her in [new complete outfit].” Select the degree and changes for the current milestone; do not apply the final result to every week.

#### Make each stage visibly different

For a script-supported weight-loss or bloating transformation, make each approved stage **noticeably slimmer and less puffy than the preceding stage**. The stomach should become smaller bit by bit, the waist more defined, and the face progressively fresher and more alive. Do not reserve every visible change for the final week. A smile or outfit change alone is not sufficient for a physical transformation.

Use a few concrete commands instead of complicated anatomical explanations: “make her stomach noticeably smaller,” “make her slimmer through the waist,” “reduce the double chin,” “remove the under-eye bags,” or “remove the double chin.” Apply these only to features present in the Before sheet and relevant to the transformation. Describe the current stage’s total change from the original Before sheet so it can be generated independently. Avoid vague wording such as “a little better” without an observable change.

Use the approved milestone count and script to distribute the transformation. For example, early stages can show a noticeably smaller stomach and reduced facial puffiness; middle stages a clearly slimmer waist and much less double chin and eye bags; a final stage a substantially smaller stomach, a slimmer silhouette, and removal of the problem-related double chin and under-eye bags when those are part of the intended result. This is a progression example, not a mandatory six-week schedule or a claim about expected product results.

The later character can look **a little younger in presentation while still looking their actual age**: a brighter, fresher face, more alert eyes, and less tiredness. Keep recognizable age features and skin texture appropriate to the style; do not change their age, recast them, make them decades younger, or erase every age line. Ordinary age-related looseness does not require preserving a problem-related double chin that the transformation is meant to remove.

#### Face progression — explicit at every physical stage

For a script-supported weight-loss or facial-puffiness transformation, write a separate, concrete face instruction into every milestone prompt. Do not rely on “less puffy,” “fresher,” a smile, or body slimming to change the face automatically. When the Before has these features, specify cheek volume, lower-face width, jawline, double chin, and under-eye bags directly. The face must become visibly narrower and more defined at each stage, as well as the body.

Describe the cumulative appearance relative to the original Before image. An early stage has visibly less rounded cheeks, a narrower lower face, a clearer jawline, and reduced but still visible under-eye bags. A middle stage has clearly slimmer cheeks, a small healthy hollow beneath the cheekbones, a much sharper jawline, substantially reduced double chin, and minimal remaining under-eye bags. At the final approved stage, explicitly say: “Give her a noticeably slim, healthy-looking face. Remove the cheek puffiness and excessive lower-face fullness. Add a slight natural hollow beneath the cheekbones, with a clearly defined jawline. Remove the problem-related double chin. Remove the under-eye bags completely.” Adapt pronouns and relevant features to the person. Avoid gaunt, sunken, skeletal, or unhealthy cheeks.

Distribute these visible changes across the actual approved milestones. If the story ends at week six, eye bags are completely gone by week six; if it ends at another marker, use that marker. Do not invent six weeks or keep the face at the same intermediate state through the final stage. The face becomes progressively clearer, brighter, and more rested while retaining actual age, natural age lines, appropriate skin texture, and recognizable identity. “Cleaner” means a clearer, fresher presentation, not dirty skin becoming clean or an airbrushed complexion.

Keep the reference identity reminder brief. Do not lock the exact cheek shape, facial fullness, under-eye area, jaw outline, hairstyle, or hair volume from the Before image. Those are transformation targets, not identity anchors. For cartoon characters, retain their exaggerated character design while reducing the relevant fullness.

Continue narrowing the established overall silhouette through the torso and waist across physical milestones. A smile, new outfit, or fuller hair cannot substitute for the face and body change.

#### Before presentation and hair progression

For a script-supported tired or unwell Before, show a person having a difficult day while still ordinarily cared for: a serious tired expression, heavy-looking eyes where relevant, less groomed styling, and practical everyday clothes. Do not default to sweat, greasy hair, dirty skin, torn or filthy clothes, or extreme dishevelment. The Before is not a caricature of poverty or neglect.

Choose the initial hairstyle for this particular person. A woman might have a simple bun, a loose ponytail, flatter curls, or everyday hair with little styling; a man might have flattened or minimally styled hair. These are alternatives, not a mandatory bun or a repeated formula for every character. Respect established hair texture, length, age, and personal taste.

Write a concrete grooming change at each later milestone, not just “nicer hair.” Early stages can show a neater arrangement and some lift. Middle stages show more visible volume and a more intentional finish. The final stage has noticeably fuller-looking, well-styled hair with volume appropriate to the person's texture and length: lifted roots, fuller curls, more body through loose hair, or another suitable treatment. For a bun-to-loose progression, retain natural color and recognizable length while changing arrangement. Do not require a haircut or invent new hair growth; the change is visual styling and volume. Do not force long, voluminous hair onto a bald or close-cropped character.

The reference carries identity and rendering, while the prompt explicitly changes grooming. Avoid “same hair” or “identical hairstyle” when that would suppress the intended improvement.

For other visible concerns, apply the same clear progression to the relevant feature, such as decreasing ankle swelling or cellulite. Do not invent slimming or physical symptoms for functional or sensory concerns without visible body changes.

#### Change outfits across elapsed weeks

For separate weeks or other distinct days, **give the character a different complete outfit at each stage by default**. Keep their established taste and age-appropriate styling, but change actual garments, not only the colors. Choose the top or dress, bottoms where relevant, a sensible layer, accessories, legwear, and shoes. Describe the new outfit briefly and clearly; keep the relevant stomach silhouette or other problem area visible enough to compare. Do not use bulky layers to hide a lack of physical change.

Use the same outfit only for a same-day continuity beat, an explicitly scripted repeated outfit, or a direct user request. Clothing must stay identical across the five views within a single generated sheet, but can and normally should change between weekly sheets. Preserve facial and hair identity rather than treating the original clothes as mandatory identity anchors.

#### Check before presenting each edit

Check that its named changes create a clear difference from the preceding approved stage, that it still references the original Before sheet, and that a new elapsed-week outfit is included. Check the face and hair explicitly: cheek fullness decreases, the jawline becomes clearer, remaining under-eye bags diminish to none by the final stage, and appropriate hair styling and volume visibly improve. If two planned physical stages differ only in smile or clothing, strengthen the relevant physical change. Keep the prompt focused on preserving identity, the few concrete changes, and the new outfit; do not add the full style master or repeat the whole base description.

### Revisions

Whenever the user requests a change, return the **entire revised prompt** in an easy-to-copy fenced `text` block. A revised base prompt repeats the full unchanged style master plus revised character description. A revised transition prompt repeats the full edit prompt only, with the upload instruction and model label above it. Never provide only a patch, fragment, or “same as above.”

## Write the descriptions

Give each character a **copyable appearance prompt**, usually 160–230 words for a character without a transformation when the full outfit needs describing, containing only approximate age, background when specified or reasonably established, precise skin shade, body build, face, hair, visible age details, skin texture, visible body hair where relevant, and a specific outfit/accessories that fit the script. Spend more words on the face than on the outfit. Make the face recognizable by describing **how its features relate**, not by stacking category labels: overall head and face silhouette; forehead and cheekbone width; eye size, spacing and lid structure; the nose's bridge, profile, tip and nostril width; cheeks, mouth, jaw, chin and neck. A nose can be especially large, long and convex in profile, short and wide, or have any other individually chosen shape; never assign a shape based on ancestry. Vary light, medium, deep, and very deep skin shades **within** each audience, especially among Black characters; avoid making every Black person the same brown. For Black characters, use natural golden, neutral, or cool brown shades as appropriate; **do not describe their skin as reddish, red-brown, copper, rust, or red-toned**. Describe what the skin actually looks like: visible pores, matte or natural sheen, uneven pigment, sun marks, fine creases, beard shadow, or other age-appropriate texture. Do not make skin waxy or uniformly airbrushed. For men and any other character with exposed arms, choose whether visible forearm or upper-arm hair is sparse, dense, dark, pale, gray, or absent; include it when it helps the reference, not as a compulsory gender marker. Select several meaningful facial relationships and one personal anchor such as a particular glasses shape, hairline, beard pattern, tooth gap, mole, or subtle natural asymmetry. **Do not describe one eyebrow as higher or more angled than the other**; this became a repetitive, artificial shorthand. Do not force any asymmetry, dental imperfection, or mark onto every face. If teeth are visible or relevant, an individual can have a small gap, uneven edge, crowded lower teeth, or a slightly crooked tooth; do not link dental traits to British or other ancestry. Keep the anchor consistent across later references. Make older people visibly their age without automatically making them tired, ill, or unattractive. Match skin, hair, and fabric detail to the chosen master: simple cartoon does not use photographic pores, grain, or fiber-level realism. **Never give women bald spots or visible thinning patches** in these character prompts; choose full scalp coverage through a plausible cut, curls, braids, locs, updo, or headwear as appropriate. Gray hair is fine. Avoid a generic perfect AI face and avoid repeating a face template across characters. Do not treat temporary expressions or selfie-angle distortion as permanent features.

## Outfit design

Use this **complete outfit formula for every character**, including standalone examples and both sides of a transformation. Make a definite choice for each visible slot; vary the actual garments and level of polish across people:

1. **Person and occasion:** why is this person dressed this way today? Put the short US casting context outside the copyable prompt.
2. **Top or dress bodice:** name the garment and its neckline/collar, sleeves, fabric, print or texture, and relevant closure or cut. Avoid the bare label “shirt” or “dress.”
3. **Bottom or dress construction:** for separates, describe the waist/rise, shape, length, and fabric of trousers, shorts, or skirt. For a dress, describe how its skirt is made and falls: wrap, buttons, panels, pleats, gathers, tiers, bias cut, belt, or another actual construction detail. Avoid generic tunics as a shortcut outfit.
4. **Layer:** make a deliberate choice about a cardigan, open overshirt, jacket, vest, blazer, shawl, or similar visible layer. Include a layer in most outfits, even with a dress, if climate and scene allow; say how it sits or is worn. If a layer would obscure the problem or make no sense, choose no layer rather than inventing one.
5. **Accessories:** choose one or two personal objects or worn details such as a belt, bag, glasses, watch, earrings, scarf, hat, or hair accessory. They need not match; do not give everyone jewelry.
6. **Legwear and footwear:** explicitly choose bare legs, socks (length and appearance), tights/pantyhose (opacity/color), or no socks as appropriate. Then name shoes with a specific shape, material, and condition, not just “flats” or “sandals.” For exposed cellulite, do not obscure the relevant skin with opaque hosiery; for swollen ankles, no socks or hosiery covering the ankle and instep.
7. **Fit and visibility:** identify where fabric pulls, hangs, creases, fades, or has been adjusted on this body, and check that any visible physical concern remains legible. Preserve recognizable pieces when the person wears the same outfit before/after; vary the garment architecture across a cast, not merely the colors.

Compress these choices into natural prose in the copyable prompt; do not print the slot labels or turn every outfit into the same sentence template.

Dress the **specific person on a specific ordinary day**, using the casting context and scene. An outfit must feel assembled by that individual over time, not filled from a generic garment template. Use the full formula even for one-piece clothes: specify the dress's bodice, sleeves, skirt construction and hem, layer, accessories, legwear, and shoes. Some people coordinate carefully; others combine practical pieces without styling them. **Favor meaningful layers, but never settle for “printed top and skirt,” “shirt and shorts,” or “dress and black shoes” with only a color change.** Vary garment type, proportions, pattern scale, fabric, legwear, footwear, and level of formality across a cast, especially when characters share age and concern. A T-shirt and jeans are allowed when true to the person, but specify their particular cut, condition, layer, socks, shoes, and personal item. Let occasion, climate, routine, and individual taste guide the outfit. Avoid treating race, ancestry, or a US region as a clothing costume. In a before/after pair, preserve recognizable pieces when the script shows the same clothes; for a changed outfit, keep the person's established taste and at least one other identity anchor.
When the script names a visible physical problem, make it clearly visible through wardrobe choices. For cellulite, use believable, varied clothes exposing the upper and outer thighs: walking shorts with an oversized worn shirt, a knee-above casual shirtdress with a relaxed tie, a patterned wrap dress, a loose romper, or another option this particular person would actually wear. Vary the full outfit across characters; do not put all affected women in the same top-plus-short-skirt formula or in implausibly tiny hems. If the script explicitly calls for other affected areas, show them through suitable clothing while staying fully clothed. Do not hide the concern under long hems or closed layers. For swollen ankles and feet, expose the lower calves as well as bare ankles and insteps with a hem well above the ankles and low-cut shoes or sandals; no socks, boots, or long trousers covering the transition. Let the footwear fit snugly without distorting the foot. Keep any extra layers from obscuring the problem. Apply the same visibility principle to other problems the script requires viewers to see. For a nonvisual concern, do not invent a body reveal or expose intimate body parts.

## Cartoon character proportions

Both Pixar styles use **strongly exaggerated cartoon faces and body proportions**. Describe a visibly enlarged head, large expressive eyes, a distinctive exaggerated nose, bold cheek/jaw/brow shapes, and an intentionally pushed full-body silhouette. Vary the dominant exaggerated features across characters. Do not use a realistic human body with a mildly stylized face.

**High fidelity changes surface detail, not the degree of cartoon exaggeration.** It adds pores, fine skin texture, hair strands, and rich fabric materials to the same bold cartoon geometry used for the regular style. Simple cartoon keeps smoother, cleaner materials. Keep people recognizably their age and individual identity in both modes.

Across transitions, retain the established exaggerated head, eyes, facial design, and stylized body architecture while visibly changing the relevant fullness. Slimming must not turn the character into a realistically proportioned human. If an edit begins looking too human, explicitly say “retain the strongly exaggerated cartoon face and body proportions.”

For a cartoon before/problem state, exaggerate **only the visible problem established by the script**. If the concern is facial puffiness, relevant choices include heavier lids, fuller cheeks, jowls, or a rounded area beneath the chin; if it is body fullness, make the overall silhouette readable. Do not apply those traits to a character whose script concerns erectile dysfunction, odor, or another issue without those visible signs. Keep swollen ankles and bloating strong but believable when they are actually relevant: recognizable legs and feet, and a fuller face, arms, torso, hips, and legs rather than an isolated pregnancy-shaped belly or extreme obesity. Preserve the same exaggerated baseline features in the after state while reducing only the script-relevant problem features. Keep the after recognizable and their actual age, while allowing a fresher, slightly younger-looking presentation.

## Characters who transform

If the script depicts a distinct **physical or presentation change**, write **one complete Before / base appearance prompt**, then one **reference-guided edit prompt per approved visual milestone** under that same character. Name the base character image as the identity reference for all later sheets. Each edit prompt uses a brief identity reminder followed by concrete changes. Avoid “keep everything the same,” “preserve all unchanged details,” or long lists of locked features. Retain the recognizable person and their actual age while allowing a fresher presentation. Change the complete outfit across separate weeks by default; preserve clothing only for same-day continuity, scripted repetition, or a direct user request. Keep facial identity and natural hair color recognizable; allow the hairstyle, arrangement, volume, and finish to change progressively with grooming. Make changes clearly visible and progressive at every physical milestone, with a progressively smaller stomach and slimmer silhouette for a weight-loss angle; do not make the result only a smile. Change only the physical problem, visible posture and expression, grooming, and clothing fit or outfit supported by that script milestone. If the chosen generation tool cannot use the base image, explain that this transition workflow requires reference-image support; do not silently convert the edit into a fresh identity generation. Do not imply that every after state must be thin, flawless, or decades younger. **Infer the visual description of a visible physical problem from the script yourself.** If it names cellulite, bloating, swollen ankles, or another visible concern, do not ask the user to explain what that looks like. Use `references/problem-areas.md` to select concrete, appropriate visual details.

When the script's problem has visible physical signs, make the **before/problem** state visually obvious and specific. Give the problem area more space than general face, outfit, or backstory (roughly 190–260 words total when the face, full outfit, and problem all need detail). Name its exact location, surface texture, shape, severity, and effect on clothing or posture. Show at least two concrete visible signs for a dominant visible problem rather than relying on a label such as “bloated” or “swollen.” For a functional or sensory concern with no visible sign, describe the stable person without fabricating one. **Never make a before/problem character smile.** Give them a serious, tired, strained, uncomfortable, or startled expression that fits the script; an open mouth can show alarm, never a happy smile. If a defining asymmetry is a crooked smile, describe the uneven mouth corners without having the person smile. When facial puffiness is central, describe the lids, under-eye area, cheeks, lower face, and jaw-to-neck boundary as relevant. In realistic style, make the condition strong but plausible; in cartoon styles, keep it clearly readable within the selected master’s controlled proportions and surface treatment. Keep unaffected body parts consistent. Do not automatically add every possible symptom: cellulite is uneven skin texture, stretch marks are lines, and bloating is generalized fullness in this workflow. **Do not add stretch marks to a bloating prompt** unless the script or user independently calls for them; bloating alone does not supply that detail. Preserve any independently established stable skin texture in the after state unless the story changes it. Describe visible signs without diagnosing a cause.
For cellulite in particular, use the tested phrasing in `references/problem-areas.md`: “pronounced cellulite,” “uneven and quilted rather than marked by separate spots,” a few shallow upper-thigh creases, and “soft, matte, and intact” skin with full, rounded thighs. Correct grammar and do not mention buttocks in the copyable prompt. Keep realistic low-relief texture even on a stylized 3D cartoon; exaggerated texture turned into embossed scales. The prompt must work without any texture-reference image attachment. Avoid long furrows, isolated round dents, repeated raised bumps, and texture on calves by default.
For swollen ankles and feet, follow the written visual guidance and failed-render lesson in `references/problem-areas.md`: show obvious but continuous fullness from exposed lower calves into broad, soft ankles and puffy insteps. Reduce ankle-bone definition while keeping normal heel and foot proportions. Avoid isolated spherical bulges at the sides and heels.

Only for bloating and weight-loss before states when the script depicts this exterior, give the character an overall heavier, moderately overweight appearance through face, neck, arms, waist, abdomen, hips, and legs, with a rounded but nonpregnant middle. When facial fullness is part of that before state, make the double chin and obscured jawline legible. **For an older character with that facial fullness, make age-related looseness visible:** one broad, heavy double chin hanging toward the upper neck, with fine micro-wrinkles and natural skin texture across it, plus lower cheeks or jowls that hang beside the mouth. Do not stack several chin folds or deep horizontal rolls. If the character is also overweight, show weight in gravity-affected forms: fuller lower cheeks and a heavier single under-chin area, soft upper arms that hang beneath the sleeves or exposed upper arm, and a lower abdomen that settles naturally rather than a smooth inflated sphere. Choose the areas the outfit reveals and describe their outline in concrete words; do not pile every sign onto everyone. In the after prompt, retain recognizable age and appropriate natural skin texture, while clearly reducing or removing the problem-related fullness, including the double chin when it is part of the intended transformation. For that weight-related before state, infer conspicuously full upper arms relative to the forearms when visible, even if the script does not name lipedema; follow the visual details in `references/problem-areas.md`. Keep skin texture appropriate to the selected master, with restrained cellulite on exposed skin when appropriate, and no automatic stretch marks. Do not make the entire person extremely obese unless the brief explicitly says so. Describe apparent fullness without claiming a diagnosis, trapped fluid, or a promised outcome.

Do not add camera, angle, lens, lighting, location, scene action, dialogue, voice, acting instructions, editing, or product directions **inside the copyable appearance prompt**. Put the short US casting context outside it; use visible physical traits, clothing, and, when relevant to a scripted presentation change, static posture and facial expression in the prompt. Do not include claims about what someone believes. Mention the rendering style only if the user specifies it and it helps the reference sheet.

## Output format

After script, style, and any necessary audience clarification, present a compact cast plan with the essential people, scene identifiers, Before/base states, distinct transition milestones, reused sheets, and total people and reference images. Wait for cast approval before writing prompts.

After approval, use one heading per character and a one-line `Casting context: [plausible US place or community, everyday occasion/routine, individual clothing habit]` outside the copyable prompt. Each character gets one complete base prompt: full unchanged selected master followed by the appearance description. Label the main character’s starting sheet `Before / base`.

For every approved later milestone, label it `Edit from Before — [time marker]`, show the bold generation-model label, instruct the user to upload the already-created Before reference image, and provide a fenced `text` block containing **only the complete identity-preserving edit prompt**. Keep supporting characters on one stable base sheet unless they also visibly transform. Present one character or transition prompt per message, starting with the main character’s Before/base sheet. Wait for the user to say “next” or request a revision before continuing. Ask one onboarding question at a time and do not dump all prompts at once. Keep explanations outside blocks minimal; do not rewrite the script or invent a cast without one.
