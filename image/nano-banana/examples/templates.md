# Part 11 — Scenario Template Library

These are copy-ready templates for the formats a paid-social ad studio actually ships. Each template is structured as hybrid labeled-prose (your default from Part 2.2). Fill the bracketed fields; don't rewrite the structure.

## 11.1 Template — Premium product hero shot

```
Subject: A [product type] with [specific material + color + finish]. Label reads "[exact label text]".
Action: [resting on / placed on / held in front of] a [surface].
Location: [environment — e.g., "marble vanity with soft blurred greenery behind"].
Composition: Close-up, product-centered, 4:5 vertical.
Camera: Shot on Canon R5, 85mm macro, f/2.8.
Lighting: Soft natural window light from [clock position], subtle specular highlight on [product surface], gentle contact shadow below.
Style: Premium commercial beauty photography, [warm / neutral / cool] cinematic color grade.
Context: For a premium DTC [category] brand's Meta ad.
```

**Use for:** hero product shots, e-commerce cover images, ad master assets.

## 11.2 Template — Lifestyle product-in-scene

```
Action: [specific action — candid and believable].
Location: [setting that matches brand aspiration — "sunlit kitchen," "rooftop at blue hour," "Mediterranean balcony"].
```

## 11.3 Template — Viral thumbnail / social hook (Vernade pattern)

This is the pattern Google DevRel uses verbatim. It works astonishingly well.

```
Design a viral thumbnail.

Face consistency: Keep the person's facial features exactly the same as Image 1 [attached], but change their expression to [look excited and surprised / look shocked / look smug].

Action: Pose the person on the [left / right] side, [pointing their finger / holding their hand up to their face / gesturing] toward the [opposite side] of the frame.

Subject: On the [other side], place a high-quality image of [the product / the scene / the headline visual].

Graphics: Add a [bold yellow arrow / circled callout / explosion shape] connecting [element A] to [element B].

Text: Overlay massive, pop-style text in the [center / bottom third]: "[EXACT HEADLINE TEXT]". Use a thick white outline and drop shadow.

Background: A blurred, [bright kitchen / cluttered desk / brand environment] with high saturation and contrast.

Composition: 16:9 landscape, text and subject both prominent.
```

**Use for:** YouTube thumbnails, high-CTR Meta static ads, TikTok cover frames.

## 11.4 Template — UGC / authentic lifestyle

```
Subject: [Age + description] with natural skin texture, [relaxed / mid-action / candid].
Action: [Specific everyday action — "applying perfume at her bathroom mirror," "pouring coffee while on her phone"].
Location: [Imperfect real environment — "messy morning bathroom with products on the counter," "small apartment kitchen with visible lived-in details"].
Composition: [Slightly off-center framing / selfie angle / overhead POV], 9:16 vertical.
Camera: Shot on iPhone selfie with direct flash, deep depth of field, slight sensor noise.
Lighting: Hard direct flash from camera, flat subject illumination, harsh shadow on wall behind.
Style: Authentic UGC aesthetic, slight motion blur, unretouched.
Context: For an organic-feeling Meta/TikTok ad in a creator-content slot.
```

**Use for:** UGC-style paid social, creator-look ads, "not-an-ad" aesthetic.

Key details that make this read as authentic rather than staged:
- "iPhone selfie with direct flash" (the canonical UGC lens — see Part 3.1.3)
- "natural skin texture" / "unretouched"
- "imperfect real environment" / "visible lived-in details"
- Slight motion blur or sensor noise

## 11.5 Template — Scent Swap / reaction-style UGC (tailored for dupe perfume project)

```
Subject: A real-looking [age + description] person sitting at a café/living room, genuine unscripted expression.
Action: Smelling a small glass fragrance sample from a blind sample vial labeled "A", then reacting naturally — [eyes widening / slight surprised smile / leaning back].
Location: Cozy well-lit interior, coffee cup and phone visible in frame, natural clutter.
Composition: Medium close-up, subject center-framed, 9:16 vertical.
Camera: Shot on iPhone front camera with direct flash, deep DoF, slight grain.
Lighting: Hard direct flash, warm tungsten ambient fill from room lamps.
Style: Authentic UGC reaction aesthetic, unretouched skin texture, candid energy.
Text: Bottom third, bold white sans-serif with drop shadow: "Sample A vs [Designer Name]".
Context: For a blind-test reaction ad on TikTok / Instagram Reels.
```

**Use for:** the Scent Swap ad concept specifically — blind-test reactions, side-by-side comparisons.

## 11.6 Template — Text-heavy poster / ad with multiple fonts

```

Composition: [Landscape / portrait / square], balanced layout with clear text zones.
```

## 11.7 Template — Comparison ad (IP-safe dupe category)

For dupe comparison ads where showing a competitor brand's logo/bottle is legally risky, use suggestive-rather-than-explicit framing:

```
Subject: Two perfume bottles side-by-side. Left bottle: a generic "designer-style" luxury bottle silhouette, intentionally blurred or abstracted, gold cap. Right bottle: a clear crisp product shot of [your product], label reads "[your product name]".
Action: Both bottles standing on a neutral surface, visual comparison.
Composition: Symmetric split composition, 1:1 square.
Camera: 50mm, f/4, clean product photography.
Lighting: Soft studio softbox from above, subtle contact shadows.
Style: Editorial minimalist commercial photography, neutral palette.
Text: Top: "Same DNA. Different price." in bold sans-serif. Bottom: "From €22.99" in thinner sans-serif.
Context: For a dupe fragrance Meta ad, legally conservative framing.
```

**Use for:** category-positioning ads where you want comparison framing without naming or depicting the designer brand explicitly.

## 11.8 Template — 2D sketch to final render

```
Reference roles: Image 1 = napkin sketch (composition and structure only). Image 2 = material/color reference.
Task: Transform the sketch in Image 1 into a [photographic / 3D render / illustrated] final image.
Subject: [What the sketch depicts].
Materials: Use the material and color palette from Image 2.
Composition: Preserve the composition and structure from Image 1 exactly.
Camera: [Specify if photographic].
Lighting: [Specify].
Style: [Final medium — photographic / 3D render / illustration].
```

**Use for:** storyboarding pitches, concept-to-ad rapid visualization, investor decks.

## 11.9 Template — Multi-language variant from one master

```
Task: Using the attached English master ad image, generate [N] variants with the text translated to [target languages: German, Italian, Spanish, etc.].
Preserve: the entire image — product, person, background, composition, lighting, color grading, font style and weight, layout positioning — exactly.
Change: only the text content, translated to each target language.
Notes: Adjust text size slightly if needed to fit the same text box after translation (German tends to run long).
Output: one image per language variant.
```

**Use for:** multi-market campaign rollouts from one creative master. Critical for your four-storefront dupe perfume setup.

## 11.10 Template — Before / after transformation

```
Task: Generate a before/after pair as two matching images.
Reference: Image 1 = "before" state.
Before: [describe current state].
After: [describe transformed state]. Preserve: [elements that must match between before and after — room dimensions, product identity, character face, framing]. Change: [specific elements — lighting, cleanliness, season, age, styling].
Composition: Both images at identical angle and framing for clean comparison.
Output: two images, matched pair.
```

**Use for:** product transformation demos (before/after product use), renovation/styling content, age-progression creative.

## 11.11 Template — Character sheet generation (one-time setup)

Run this once per recurring AI persona to generate the character sheet you'll re-use across sessions.

```
Subject: A [age + gender + detailed physical description — be very specific: hair color and cut, eye color, skin tone, any distinguishing features like freckles or dimples, build].
Action: Standing neutrally, arms at sides, neutral expression.
Composition: Character sheet layout on a single canvas, showing five views in a row:
  - Far left: full profile view (90° left)
  - Left: 3/4 left view
  - Center: front view straight-on
  - Right: 3/4 right view
  - Far right: full profile view (90° right)
Background: neutral gray seamless, consistent across all five views.
Camera: 85mm, f/5.6 (deep DoF, all views sharp), even framing.
Lighting: Neutral three-point softbox, consistent across all five views.
Style: Clean reference photography, no stylization.
Output: 16:9 landscape, single image with all five views.
```

**Use for:** one-time character sheet generation. Save the output; re-use as reference for all subsequent production.

## 11.12 Template — Infographic with grounded data (verify before shipping)

```
Task: Create an infographic visualizing [topic].
Search and source: [what data to retrieve — e.g., "current market share of top 5 fragrance brands in Europe 2026"].
Visual translation: [chart type — bar chart / pie chart / timeline / map].
Style: Clean editorial infographic, minimalist, [color palette], bold sans-serif typography, clear hierarchy.
Composition: 16:9 landscape with clear title, data visualization centered, source note at bottom.
Text: Title: "[headline]". Data labels: from the search. Footer: "Source: [citation]".
Verify all data before shipping.
```

**Use for:** pitch decks, research-backed social posts, internal strategy visuals. **Always manually verify the data output before any external use.**

## 11.13 Template — Pattern-interrupt / cartoon-style ad

Based on the Essence Vault cartoon-ad pattern validated as a whitespace in the dupe perfume category:

```
Subject: A stylized cartoon-illustrated character [brief description], mid-action, with [exaggerated expression].
Action: Reacting to / discovering / showing off [the product — rendered in same illustrated style].
Location: [Simple illustrated setting with flat color background].
Composition: Medium shot, subject center-framed, 9:16 vertical.
Style: 2D illustrated animation style, bold flat colors, thick clean outlines, 4-color palette — [specify colors, e.g., "cream, soft coral, deep navy, warm mustard"]. Inspired by mid-century cartoon aesthetics.
Text: Speech bubble above character: "[exact line]" in bold handlettered-style font, black.
Context: For a pattern-interrupt TikTok/Meta ad, scroll-stopping cartoon aesthetic.
```

**Use for:** pattern-interrupt creative that breaks the UGC/product-photo visual monotony of a feed.

## 11.14 Template — Minimum-viable quick prompt (short prose)

For when you just need something fast:

```
A [subject] in a [setting], [lighting + camera in one phrase], [style], [aspect ratio].
```

**Example:**
> A cream-colored perfume bottle on a sunlit marble surface, shot on film with soft morning light, editorial style, 4:5 vertical.

That's it. Use this for rapid exploration, first-pass concepts, or low-stakes assets.

# Part 15 — Canonical Templates (Quick Reference)

Compact, drop-in templates. Fill fields, don't rewrite structure. For the expanded scenario library see Part 11.

## 15.1 Photorealistic person (generate)

```
Subject: [age] [gender presentation], [hair + appearance], natural skin texture. [Expression], [gaze].

Location: [setting].
Composition: [framing], [aspect ratio].

```

## 15.2 Identity-locked edit

```
[Reference attached]
Preserve: facial features, bone structure, skin tone, hair color, age, gender presentation.
Change: [bounded changes only].
Preserve also: [lighting direction and intensity / camera angle / background] unless listed as change.
```

```

Lighting: Soft commercial studio / natural window from [direction]. Subtle contact shadow.
Materials: [accurate material spec].

```

## 15.4 Text-heavy poster

```
Subject: [main visual].
Text: Render text elements:
  - Line 1: "[exact text]" in [font description], [color], [position].

  - Line 3: "[exact text]" in [font description], [color], [position].
Location: [background that supports legibility].
Composition: [layout], [aspect ratio].
Style: Commercial poster.
```

## 15.5 Multi-image composite

```
Reference roles: Image 1 = [role]. Image 2 = [role]. Image 3 = [role].

Preserve from Image 1: [specific elements].
```

## 15.6 Enumeration / accuracy-critical

```
Task: Generate accurate visualization.
Subject: Exactly [N] instances of [object].
Order: [explicit order or arrangement].
Rules: No additional objects. No perspective exaggeration. Accurate relative scale.
Location: [neutral or contextual].
Camera: [orthographic or realistic lens, specify].
Style: Clean factual visualization.
```

## 15.7 Conversational edit (inside a session)


No template needed; conversational natural language works.
