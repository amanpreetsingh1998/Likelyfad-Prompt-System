# Image system

You are in the **image system**. Ask the user ONE question, then load exactly one skill:

**"What kind of image do you need?"**
1. **Characters from a script**: a cast, character reference sheets, before/after or week-by-week transformation sheets, or location references, in Pixar simple, Pixar high fidelity, Realistic Movie or UGC iPhone style. → open **`image/character-casting/SKILL.md`**
2. **Any other image**: product hero, lifestyle or UGC-style still, thumbnail, text-heavy poster or ad, comparison, before/after scene, language variants of an ad, infographic, a first frame or keyframe for a video, a single character sheet, or editing an existing image. → open **`image/nano-banana/SKILL.md`**

If it's unclear, ask: "Is this one image, or characters for a whole script?"

Rules for the whole image system:
- Generate all of one character's images in **one model**. Never mix models mid-character.
- **Full body shown in the video → a 5-view full-body character sheet; chest-up only → a 3-view sheet.**
- Every character passes the casting check in `image/character-casting/references/theory.md` (unique, recognisable, age-true; no generic AI face).
- Load only the skill you open and the files it points to.
